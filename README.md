# Claude Code Skills & Commands

Personal collection of Claude Code skills and commands, organized around the **Vibe Engineering** workflow: Spec > Plan > Build > Verify > Ship.

Superpowers skills forked from the [superpowers plugin](https://github.com/anthropics/claude-code-plugins) and adapted for our workflow. Kept as a personal copy so plugin updates don't break our setup.

## Spec

| Skill | Description |
|-------|-------------|
| `brainstorming` | Explore ideas, requirements and design before implementation |
| `agent-design` | Guide for designing AI agent architectures |

## Plan

| Skill | Description |
|-------|-------------|
| `writing-plans` | Implementation plan authoring with bite-sized tasks |
| `parallel-plan-execution` | Wave-based parallel task execution |
| `dispatching-parallel-agents` | Parallel agent dispatch patterns |

## Build

| Skill | Description |
|-------|-------------|
| `vibe-engineering` | Disciplined AI-assisted development methodology |
| `test-driven-development` | Red-green-refactor discipline |
| `using-git-worktrees` | Isolated workspace management |
| `systematic-debugging` | Root-cause investigation before fixes |
| `copy-website` | Clone/replicate live website designs |
| `react-doctor` | Catch issues in React projects |

## Verify

| Skill | Description |
|-------|-------------|
| `verification-before-completion` | Evidence before completion claims |
| `requesting-code-review` | Dispatch code review subagents |
| `receiving-code-review` | Handle review feedback with technical rigor |

## Ship

| Skill | Description |
|-------|-------------|

## Meta

| Skill | Description |
|-------|-------------|

## Commands

| Command | Description |
|---------|-------------|
| `push` | Quick commit and push |
| `review` | Interactive code review |

## Usage

Copy skills to `~/.claude/skills/` and commands to `~/.claude/commands/`.
